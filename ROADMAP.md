# Roadmap

## Активный объём: минимальный сетевой прототип (2026-11-23)

По прямому указанию пользователя объём сокращён. Ближайшая цель — два
управляемых персонажа в одной заранее выбранной сцене Mafia II Classic.
Остальные пункты старой дорожной карты ниже отложены, не являются текущей работой.

1. Два клиента подключаются к одной сессии; каждый видит отдельного гостя.
2. Передаются только появление, позиция, поворот и отключение.
3. Гостевой аватар следует сетевому состоянию без борьбы с собственным ИИ.
4. При потере связи/выгрузке сцены аватар прекращает обновление и удаляется
   штатно, без вмешательства в локального Вито и исходный профиль.
5. Критерий MVP: реальное движение на двух ПК, видимое с обеих сторон,
   штатное отключение, отсутствие новых сбоев и изменений исходных сохранений.

Пока исключены: бой/урон, NPC, машины/пассажиры, синхронизация миссий,
катсцен, контрольных точек, сохранений и восстановление после переподключения.
Свободная прогулка будет результатом этого MVP, а не доказательством сюжетного
кооператива. Существующая сеть/observer переиспользуются; новые подсистемы вне
этого минимума не добавлять. Проверки выполнять только для изменённого поведения.

Статусы на 2026-11-18. Полный объём основной кампании сохранён; таблица не означает обещания технической достижимости.

## Следующая техническая проверка

Закончить игровую проверку read-only адаптера позиции: исключение периода загрузки, два открытия миссии, прекращение снимков в меню и чистый выход. Установить настоящий идентификатор главы/состояния миссии: локальная epoch его не заменяет. Затем исследовать создание второго персонажа без нарушения сюжетного игрока и сетевой обмен реальными снимками. Каждый новый адрес/вызов отдельно проверить на GOG EXE; не переносить автоматический запуск `freeride` из m2o-reborn.

## Критические неизвестные

- Отличия кода и адресов установленного GOG EXE от Steam-версии SDK.
- Безопасный игровой callback для создания/обновления сущностей.
- Создание удалённого персонажа с работающим локальным сюжетным игроком.
- Наблюдение глав, checkpoint, Lua-сценариев и загрузок без отключения кампании.
- Управление гостевыми копиями NPC и сюжетными автомобилями.
- Наличие второго компьютера/игрока для обязательной проверки Radmin VPN.
