# Сохранение на GitHub

Назначение: https://github.com/GorkovSer/MafiaII-Coop , ветка `development`. Репозиторий создан приватным. Не менять его видимость или доступы в ходе сохранения.

После содержательного этапа:

1. Проверить `git status`, diff и состав файлов; добавлять только явно перечисленные файлы этапа.
2. Выполнить подходящие проверки и записать фактический результат, включая отсутствующие игровые испытания.
3. Проверить staged diff и отсутствие секретов, личных данных, игровых файлов и материалов без права распространения. `.gitignore` не заменяет проверку уже отслеживаемых файлов.
4. Создать понятный commit; если код не собирается — явно WIP с причиной.
5. Отправить `git push -u origin development` без force.
6. Сопоставить `git rev-parse HEAD` с `git ls-remote origin refs/heads/development`. Только совпадение означает подтверждённую выгрузку.
7. Сообщить результат и ссылку на commit.

Если push отклонён из-за новых удалённых изменений, сначала сохранить локальные изменения, получить ветку и объединить без переписывания опубликованной истории. При недоступности сети сохранять локальные commits и сообщать, что они ещё не выгружены.

Сборки не добавлять в Git. После прохождения критериев этапа: проверить архив, лицензии, отсутствие игры/секретов, создать версионный tag и Release; незавершённое — prerelease. В описании явно указать статус испытаний двух ПК через Radmin VPN. Пока критерии этапа не пройдены, tag/Release не создавать.

Этот порядок действует во время активной работы в чате. Фоновой задачи, которая сама коммитит или выгружает после завершения чата, нет.
