# Codex: установить сборку и провести парный тест

Этот файл пользователь может прямо поручить выполнить Codex на каждом ПК.
Работай только на своём ПК. Сначала установи/подготовь сборку, затем дождись
общей команды пользователя **«Старт»**. Второй Codex не доступен автоматически;
готовность и команды между компьютерами передают сами игроки.

## Готовый запрос для друга — роль гостя

> Установи и подготовь Mafia II Coop по инструкции
> https://github.com/GorkovSer/MafiaII-Coop/blob/development/docs/CODEX_TWO_PC_RUNBOOK.md.
> Я гость. IP хоста в Radmin: ВПИШИ_IP_ХОСТА.
> Найди мою Mafia II Classic, скачай готовую сборку с лаунчером, проверь и
> распакуй её, настрой гостя. Дойди до этапа «Готов к старту» и дождись моей
> команды «Старт». После неё запускай игру и проведи местную часть парных
> тестов по этой инструкции. Оригинальные сейвы и файлы игры не меняй.

Заменить ВПИШИ_IP_ХОСТА реальным адресом. Если адрес ещё не известен, подготовь
сборку независимо, затем один раз запроси IP хоста. Не подставляй свой IP/localhost.

Для хоста тот же запрос, но **«Я хост»**; свой адрес взять из Radmin. На этом
ПК Ева также ждёт команды пользователя. Публикация этой инструкции сама по себе
не означает разрешение немедленно запускать игры в текущем чате.

## 1. Установка — выполнить самостоятельно

1. Не перечитывай всю историю разработки. Для этого теста достаточно данного
   файла и docs/TWO_PC_TEST.md. Это предварительный визуальный MVP, не сюжетный
   кооператив. Новый лаунчер ещё не прошёл пользовательскую приёмку.
2. Найди установленную Mafia II Classic: сначала указанный пользователем путь,
   обычные папки Games и записи библиотек Steam/GOG; избегай полного повторного
   обхода дисков. Нужен `pc/mafia2.exe` с SHA-256:
   `16c79a3be483e582719e43d7b451e887e89414be81ca7ecfc0536dd8185e6c2f`.
   При другом EXE сообщи о несовместимости; не патчи и не подменяй его.
3. Скачай **готовый ZIP**, не Source code и не отдельный EXE:
   https://github.com/GorkovSer/MafiaII-Coop/releases/download/v0.0.6-launcher-preview.20261127/MafiaII-Coop-launcher-preview-20261127.zip
   Ожидаемый SHA-256:
   `91782af066ce787807f9326944c38cd40e40b054214be4f28697edc8eb782c00`.
   При несовпадении останови установку. Не заменяй автоматически другой версией.
4. Распакуй целиком в новую короткую папку, например
   `C:\MafiaCoop\preview-20261127`. Уже существующую установку не стирай и не
   перезаписывай вслепую: используй отдельную папку. Мод и лаунчер уже включены,
   копирование DLL в установленную игру, компиляция и права администратора не нужны.
5. В корне распакованного preview должны быть `MafiaII-Coop.exe`, scripts, build,
   testdata и `visual-preview-manifest.json`. Проверь хеши перечисленных в manifest
   файлов и что пути остаются внутри папки preview. Исходники пакета: `d3c17d0`.
6. Убедись, что оба пользователя вошли в одну сеть Radmin. Если сеть/IP/доступ
   отсутствуют, попроси пользователя подключить Radmin и передать IP хоста;
   не угадывай пароль сети и не публикуй его. Не отключай защиту Windows целиком.
7. Если Mafia II уже открыта, попроси обычный выход; не закрывай её принудительно.
   Открой `MafiaII-Coop.exe`, выбери назначенную роль, IP хоста и найденную папку
   игры. Хост указывает СВОЙ Radmin IP; гость — ТОТ ЖЕ адрес хоста. Порт уже 28960.
   Пока не нажимай кнопку запуска игры.

Если инструменты/политика среды требуют отдельного подтверждения запуска скачанной
программы, объясни это пользователю и используй штатное подтверждение. Не обходи
ограничения и не выдавай отсутствие доступа к GUI за успешное открытие окна.

## 2. Контрольная точка «Готов к старту»

Напиши: роль, найденная папка игры, совпадение хешей, готовность Radmin/IP и
«Готов к старту, игру ещё не запускал». Пользователи сообщают друг другу готовность.
Не создавай фоновые задания и не начинай общий тест по таймеру или молчанию.

## 3. После общей команды «Старт»

1. Хост нажимает «Создать сессию и запустить игру», гость — «Подключиться и
   запустить игру». Точная одновременность не нужна: гость повторяет попытки
   соединения, пока хост готовится. Обе роли используют тот же ZIP и порт.
2. Сразу дважды Escape для пропуска интро; звук выключить только у Mafia II,
   не у других приложений. Войти через обычное меню «Продолжить»; не вызывать
   backend Continue, не править память и не имитировать загрузку по одному логу.
   Предпочитать оконный режим; при наличии согласованного второго монитора
   перенести тестовую игру туда. В пользовательском лаунчере выбора монитора нет.
3. Визуально подтвердить загруженную контрольную сцену. Хост остаётся в ней,
   один игрок отходит на пару шагов. Соединение/remote_active без видимого второго
   персонажа не считать успехом. Текущий личный сейв хоста не передаётся.
4. Провести одним сеансом сценарии из docs/TWO_PC_TEST.md: движение и поворот
   по очереди, несколько минут наблюдения, пауза/продолжение обоих, выход и
   повторное подключение гостя, затем выход хоста. Перезапуск задания — отдельным
   последним сценарием: после смены сцены нужен новый запуск preview обоим.
   Не перезапускай игры после каждого отдельного движения/проверки.
5. Каждый Codex наблюдает СВОЙ экран и собирает СВОИ журналы. Согласуйте через
   пользователей фразы «иду», «поворот», «пауза», «выхожу». По возможности сохраните
   короткие видео с общей голосовой точкой отсчёта. Без записи/наблюдения второго
   экрана не утверждай, что видишь происходящее на другом ПК.

## 4. Завершение и результат

Закрыть игры обычным способом. В своей установке выполнить
`scripts/visual-session-report.ps1 -SessionDirectory <своя папка work/probe-sessions/ID>`.
Сохранить оба отчёта, видео/скриншоты и при ошибке `work/crashlogs` вместе с
соответствующей сессией. Здесь JSON/текстовые диагностики, не все нативные дампы игры.
Дать краткий результат по каждому сценарию: прошёл / не прошёл / не наблюдался.
Проверить отсутствие дублей, баланс созданий/удалений, exit 0, profile changes 0.
Сопоставить результаты через пользователей; пинг VPN не выдавать за задержку модели.
Сырые логи с IP, личные пути и сейвы в публичный GitHub не загружать.
Если обнаружен дефект, сначала зафиксировать шаги и доказательства; не менять
версию только на одном ПК посреди теста. Код исправлять отдельным согласованным этапом.
