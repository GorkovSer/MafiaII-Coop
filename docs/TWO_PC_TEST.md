# Подключение на двух компьютерах

**Если установку и тесты делает Codex:** передайте ему
[этот пошаговый сценарий с готовым запросом](CODEX_TWO_PC_RUNBOOK.md).
Он установит готовый ZIP, подготовит свою роль и дождётся общей команды «Старт».

Это предварительная сборка для твоей проверки. Новый EXE-лаунчер и реальное
соединение двух ПК ещё не прошли приёмку. Сейчас доступны видимая модель второго
игрока, её перемещение и поворот; без анимации ходьбы, столкновений и общего сюжета.

## Что скачать

Обоим скачать **один и тот же ZIP из Assets на странице Releases** репозитория
GorkovSer/MafiaII-Coop. Архивы «Source code» — исходники, запускать из них нельзя.
Распаковать ZIP целиком в короткую папку, например `C:\MafiaCoop`. Не вынимать один
EXE: рядом с ним должны остаться scripts, build, testdata и manifest.
На каждом ПК нужна совместимая Mafia II Classic; неподходящий EXE мод отклонит.
В папку установленной игры ничего копировать не нужно. Администратор не требуется.

## Как подключиться

1. Оба подключаются к одной сети Radmin VPN и видят друг друга в её списке.
2. **Хост:** открыть `MafiaII-Coop.exe` в распакованной папке, выбрать «Хост»,
   свой IPv4 из окна Radmin и свою папку Mafia II Classic. Нажать «Создать сессию
   и запустить игру». Передать этот IP другу. Порт автоматически 28960.
3. Хост пропускает интро двумя Escape, выбирает обычное «Продолжить» и остаётся
   в начальной сцене контрольного сохранения. Ждать друга в меню не требуется.
4. **Друг:** открыть тот же лаунчер на своём ПК, выбрать «Гость», ввести
   **IP хоста**, а не свой, и выбрать свою папку Mafia II Classic. Нажать
   «Подключиться и запустить игру», два Escape и обычное «Продолжить».
5. Соединение выполняется автоматически. Один игрок отходит от общей точки
   появления на пару шагов — второй персонаж должен стать различим.

Оба загружают одинаковый контрольный сейв в отдельных профилях. Твой текущий сейв
другу **не передаётся**, исходные сохранения не используются для этой проверки.
Гость может зайти после загрузки хоста, пока хост остаётся в согласованной сцене.
Меню подключения внутри Mafia II нет. Окно лаунчера можно закрыть, игру — обычным
выходом; после смены/перезапуска задания нужно заново запустить preview обоим.

## Один общий тест на 5–10 минут

- По очереди пройти несколько метров, повернуться стоя; второй смотрит на модель.
  Проверить правильное направление, отсутствие рывков и независимость управления.
- По очереди пауза/продолжение: модель должна исчезать и возвращаться без дублей.
- Друг выходит обычным способом и подключается снова, хост остаётся на месте.
  Затем проверить выход хоста: у гостя не должна оставаться зависшая модель.
- Перезапуск задания — в конце: модели должны быть отозваны до нового запуска
  preview. Сам перезапуск не означает синхронизацию миссий.

## Как наблюдать и что прислать

На каждом ПК записать короткое видео своей игры. Перед движением вслух сказать
«иду», «поворачиваюсь», «пауза» — так можно сопоставить действия и изображение.
Ева управляет только твоим ПК; автоматически видеть экран друга она не сможет.
Второй Codex может наблюдать локально на его ПК, но записи и результаты нужно
передать нам отдельно. Пинг Radmin сам по себе не доказывает задержку аватара.

При ошибке сохранить её текст/скриншот, папки `work/crashlogs` и нужную сессию из
`work/probe-sessions`. Кнопка «Крашлоги» ведёт к отчётам лаунчера/worker; это не
нативные minidump игры. Сырые логи, IP и сейвы не выкладывать в публичный GitHub.
Если связи нет: сверить IP хоста, общую сеть Radmin и доступность UDP 28960;
не отключать защиту Windows целиком. Сообщить, на каком из шагов возникла ошибка.

Codex после обычного выхода на каждом ПК: выполнить
`scripts/visual-session-report.ps1 -SessionDirectory <папка сессии>` и сопоставить
оба отчёта с видео. Критерии: видимая модель на обоих экранах, отсутствие дублей,
сбалансированные создания/удаления, exit 0 и изменения исходного профиля 0.
Один лишь remote_active или успешный запуск лаунчера не означает пройденный тест.
