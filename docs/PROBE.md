# Диагностическая загрузка 0.0.1

Это собственный код для проверки загрузки DLL в 32-битную игру. Он не реализует кооператив, не вызывает SDK и не патчит игровые инструкции. Он не доказывает работоспособность кампании.

## Сборка

Портативная LLVM-MinGW 20261104, clang 23.1.5, вариант msvcrt-x86_64, с поддержкой i686 target. Скачать с https://github.com/mstorsjo/llvm-mingw/releases/tag/20261104 и проверить SHA256 по `dependencies/toolchain.json`.

```powershell
./scripts/build-probe.ps1 -Toolchain <каталог-llvm-mingw>
```

Сборка создаёт только собственные `build/probe/coop_probe.dll`, `probe_launcher.exe`, тестовый `probe_host.exe`. Игровые DLL не нужны для компиляции. Статически связывается runtime toolchain; её LICENSE-файлы нужны при будущем распространении бинарников.

## Проверка загрузчика

Сначала выполнить загрузку в собственный `probe_host.exe`, используя абсолютные пути трёх аргументов загрузчика: EXE, DLL, новый локальный log. Файл должен содержать `pointer_bits=32`, `status=loaded_inside_process`, соответствующий PID. Это тест реального DLL loader, не тест двух игроков.

## Проба в игре

```powershell
./scripts/start-probe.ps1 -GameDirectory 'D:\Games\Mafia II Classic'
```

Скрипт допускает только проверенный SHA256 GOG EXE, отказывает при уже запущенной Mafia II, копирует найденные сохранения в игнорируемый `work/probe-sessions`, снимает хеши DLL/EXE/config и запускает новый игровой процесс. Если каталогов сохранений не найдено, это фиксируется отдельно. Существующие файлы логов не перезаписываются.

`-WaitForExit` удерживает нативный handle созданной игры, сообщает код её завершения и позволяет наблюдать жизненный цикл. Для воспроизводимой проверки загрузчика без игры выполнить `./scripts/test-probe.ps1`: реальное DLL loading, совпадение PID, нормальный выход test host, отказ перезаписывать log и отказ при отсутствующей DLL.

Нативный загрузчик загружает DLL только в созданный им процесс. `CoopProbeStart` вызывается после завершения LoadLibrary, вне DllMain; пишет локальный log и возвращается. При ошибке загрузки завершается только созданный процесс. При успехе игра остаётся открытой для проверки пользователем. В игру не копируются файлы. Для удаления достаточно закрыть игру; обычный запуск не загружает DLL. Локальные материалы испытания сохраняются отдельно.

Игра может сама изменять конфигурацию и сохранения во время обычного запуска, поэтому резервное копирование выполняется до старта. SDK-адреса ещё не проверены; в probe они не используются.
