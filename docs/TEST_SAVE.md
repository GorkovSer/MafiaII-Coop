# Скачать и установить контрольный сейв

Пользователь явно поручил опубликовать свой сейв в этом репозитории и дать
соавтору указание скачать и установить его. Исключение относится только к
`testdata/story-save.zip`; прочие сохранения, резервные копии и журналы не публиковать.
Видимость/доступы репозитория не менять.

**Соавтору: перед игровыми тестами скачай и установи этот сейв.** Получи актуальную
ветку `development` через обычный `git pull` своего клона либо скачай
[архив на GitHub](https://github.com/GorkovSer/MafiaII-Coop/blob/development/testdata/story-save.zip)
кнопкой Download raw file. Доступ к приватному репозиторию требуется обычный.
Не скачивай HTML страницы вместо zip. Установщик и manifest бери из того же commit.

```powershell
./scripts/install-test-save.ps1
# Если архив скачан отдельно:
./scripts/install-test-save.ps1 -BundlePath 'C:/path/to/story-save.zip'
```

Установщик проверяет SHA256 по `testdata/story-save.json`, требует закрытую игру
и распаковывает **новый** профиль внутри `work/probe-sessions/<id>`.
Он не перезаписывает существующий профиль и не пишет в настоящий LOCALAPPDATA.
Поэтому существующий прогресс соавтора остаётся на месте; start-probe дополнительно
снимает его резервную копию перед каждым тестом. Если путь уже существует,
установщик отказывает вместо замены.

Сохрани выданное `TestProfileFrom=<id>` и запусти:

```powershell
./scripts/start-probe.ps1 -GameDirectory 'D:/Games/Mafia II Classic' -Observer -WaitForExit -BuildDirectory build/human-settled-test -TestProfileFrom <id>
```

Путь игры и каталог своей собранной DLL подставь по своему компьютеру.
Далее выполняй **быстрый вход из [GAME_UI.md](GAME_UI.md)** с PID и ID новой
запущенной сессии, а не ID установленного seed. Вход идёт через обычный
Continue Story, внутренний `-ContinueMainStory` не включать.

Это комплект профиля, который реально использовался в наших проверках:
снежная улица с Вито, задача идти к Джо. В комплект входят sav1/sav100/sav200,
profile.dat, last.dat, vfs.bin и изолированный videoconfig.cfg. Служебная привязка
профиля сохранена для совместимости; архив содержит метаданные игрового профиля.
Оригинального EXE, DLL и игровых ресурсов в архиве нет. Видеоконфигурация касается
только тестового профиля; `-SecondScreen` задаёт окно 1280×720 на втором экране.

Для обычных тестов не копируй комплект поверх личных сохранений. После установки
проверь сцену и требуемую сборку EXE. Работа этого же save на другом ПК/издании
пока не подтверждена; это ещё не доказательство двухклиентского кооператива.
