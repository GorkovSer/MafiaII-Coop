# Mafia II Coop

Текущий сокращённый этап: [визуальный сетевой MVP](docs/VISUAL_MVP.md) — отдельная
видимая модель с движением и поворотом, пока без анимации ходьбы и столкновений.
Переносимый запуск проверен в настоящей игре отдельно для host и guest с тестовым
сетевым peer; совместная проверка двух ПК через Radmin VPN ещё впереди.

Экспериментальная разработка кооператива основной кампании Mafia II для двух игроков через Radmin VPN.

**Статус: исследование и проверка основы. Играбельного кооперативного мода пока нет.**

Первый целевой вариант: Mafia II Classic, установленное GOG-издание. Совместимость конкретного EXE с найденными SDK ещё не установлена. Definitive Edition и DLC не входят в первый объём.

Хост ведёт сюжет и сохраняет прогресс; гость управляет отдельным персонажем и помогает в бою и поездках. Free roam сам по себе не считается выполнением задачи.

Исходные игровые ресурсы и резервные копии не публикуются. По прямому поручению пользователя добавлен один контрольный сейв с установщиком отдельного профиля. В GOG EXE подтверждены callbacks, загрузка через обычное меню, самостоятельное движение и передача активных координат через ENet. Отдельный opt-in тест создал видимого локального Human и подтвердил его удаление через реестр сущностей. Быстрый вход повторяет Enter до начала загрузки; выход отправляет Alt+F4 и немедленный Enter. Это диагностическая разработка: применение состояния удалённого игрока к управляемому аватару и совместное прохождение ещё не реализованы. Испытание двух игровых клиентов на разных ПК через Radmin VPN остаётся впереди.
