# Mafia II Coop

Экспериментальная разработка кооператива основной кампании Mafia II для двух игроков через Radmin VPN.

**Статус: исследование и проверка основы. Играбельного кооперативного мода пока нет.**

Первый целевой вариант: Mafia II Classic, установленное GOG-издание. Совместимость конкретного EXE с найденными SDK ещё не установлена. Definitive Edition и DLC не входят в первый объём.

Хост ведёт сюжет и сохраняет прогресс; гость управляет отдельным персонажем и помогает в бою и поездках. Free roam сам по себе не считается выполнением задачи.

Исходные игровые файлы, сохранения и резервные копии не публикуются. Внутри GOG EXE подтверждены callbacks, открытие/закрытие миссии и нормальный выход ранней диагностической сборки. Добавлен ENet transport с отдельным worker и проверками host/guest в двух локальных процессах; из меню реальной игры получены inactive-сообщения. Тесты идут в окне на втором экране с отдельным профилем. Это ещё не кооперативный мод: второй персонаж, применение удалённого состояния и совместное прохождение не реализованы. Последняя игровая приёмка чтения позиции/сетевой передачи остаётся открытой.
