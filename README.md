# Mafia II Coop

Экспериментальная разработка кооператива основной кампании Mafia II для двух игроков через Radmin VPN.

**Статус: исследование и проверка основы. Играбельного кооперативного мода пока нет.**

Первый целевой вариант: Mafia II Classic, установленное GOG-издание. Совместимость конкретного EXE с найденными SDK ещё не установлена. Definitive Edition и DLC не входят в первый объём.

Хост ведёт сюжет и сохраняет прогресс; гость управляет отдельным персонажем и помогает в бою и поездках. Free roam сам по себе не считается выполнением задачи.
